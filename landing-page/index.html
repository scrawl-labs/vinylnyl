Seeing an "unidentified developer" warning?

Vinylnyl isn't notarized by Apple yet, so macOS may warn that it can't verify the developer the first time you open it. Control-click (or right-click) the app icon and choose "Open" — you'll get an "Open Anyway" button. Or run this command once in Terminal instead.

xattr -cr /Applications/Vinylnyl.app
